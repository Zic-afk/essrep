04 / ВЫ СЕЙЧАС ЗДЕСЬ

Мир по имени
Giovanna.

Этот сайт — тоже проект. Вместо списка ссылок мы создали планету, на которой можно исследовать нашу работу, находить созвездия и путешествовать между продуктами.

01 / ИДЕЯ

Портфолио как мир

Каждый проект получает своё место на планете. Giovanna объединяет их и сама становится частью коллекции.

02 / НАВИГАЦИЯ

Выбрать направление

Планету можно вращать, проекты — выбирать по маякам, стрелками или через список. Карточка даёт познакомиться с продуктом до путешествия.

03 / ОЩУЩЕНИЕ

Живой интерфейс

Созвездия меняют рисунок, спутники отвечают на действия, а карточки мягко наклоняются вслед за курсором.

04 / РЕАЛИЗАЦИЯ

Пиксели, код и движение

Canvas рисует мир, CSS задаёт объём и переходы, JavaScript связывает взаимодействия. Без Three.js и внешнего 3D-движка.
