# ESSCALE — планета проектов

Локальный MVP редизайна esscale.ru. Откройте `index.html` в браузере; установка, сервер и интернет для самого сайта не нужны. Главная занимает один экран с планетой, заголовком и кнопкой «Рассчитать проект». Кнопка открывает `pages/calculator.html`.

## Что реализовано

- Большая целая пиксельная планета с маяками WearningLords, Scandere и GoPhoto.
- Выбор маяка, доворот, приближение через облака и переход на локальную страницу проекта. Полёт можно отменить кнопкой или Esc.
- Ссылки «На орбиту» на страницах проектов запускают обратный полёт: облака закрывают кейс, затем камера отдаляется от точки проекта до общего вида планеты. Анимацию можно пропустить кнопкой или Esc; при уменьшении движения возврат мгновенный.
- Автовращение планеты при открытии главной (полный оборот примерно за минуту). Пауза действует до следующего открытия страницы; при возврате «На орбиту» сохраняется поворот. При уменьшении движения автовращение отключено и страницы открываются сразу. Прямые ссылки и открытие в новой вкладке работают без полёта.
- Компактный список проектов в диалоге на главной; без JavaScript отображаются прямые ссылки на кейсы.
- Пять раскрывающихся направлений и контакт на странице калькулятора.
- Калькулятор: 8 серверных работ, 5 мобильных, 3 коэффициента. Коэффициенты перемножаются и применяются только к серверу. EP округляются до двух знаков; недели — вверх. Ставки: 3 500–5 000 ₽/EP, скорость — 15 EP/неделю.
- Передача состава расчёта в черновик сообщения Telegram. Сайт ничего не отправляет автоматически.
- Мобильная компоновка, клавиатурный фокус, уменьшение движения, остановка отрисовки вне видимой области.
- Локальный кириллический шрифт Orbit Pixel и иконка сайта.
- Созвездия проявляются при наведении, по касанию и с клавиатуры; линии плавно исчезают после взаимодействия.
- Нажатие на спутник, зонд или станцию раскрывает антенну и запускает короткие сигнальные импульсы. Кнопки доступны с клавиатуры; скрытые за планетой объекты не перехватывают нажатия.

## Файлы

```text
index.html                       Главная — планета
css/                             Стили
  style.css                      Основное оформление и адаптивность
  pixel-design.css               Пиксельные рамки и типографика
  orbit.css                      Планета, маяки, переходы и кейсы
js/                              Браузерный JavaScript
  app.js                         Сцена и переходы
  data.js                        Проекты и логика калькулятора
  orbit-math.js                  Геометрия и проекции
  space-objects.js               Пиксельные спутники, корабль, станция, НЛО и метеориты
  constellations.js              Интерактивные созвездия
  site.js                        Интерфейс калькулятора
  project-page.js                Прибытие на проект и обратный переход через облака
pages/                           Калькулятор и три страницы проектов
assets/                          Иконки, рамка и локальный шрифт
scripts/                         Генераторы страниц и шрифта
tests/                           Проверки путей, логики и браузерных сценариев
docs/planet-portfolio-plan.md     Исходный план
artifacts/previews/               Снимки экрана
artifacts/browser/                Служебные профили тестового браузера
```

Генерация страниц: `node scripts/build-projects.js`. Генерация шрифта: `python scripts/build_font.py`. Генераторы определяют папку проекта по своему расположению, поэтому работают и при запуске из другой рабочей папки. Страницы проектов нужно править через `scripts/build-projects.js`, чтобы изменения сохранялись при повторной генерации.

Команды проверок из корня:

```text
node tests/paths.test.js
node tests/calculator.test.js
node tests/scene.test.js
node --check js/app.js
node --check js/site.js
```

`paths.test.js` проверяет локальные ссылки всех пяти HTML-страниц, якоря, пути к стилям, скриптам, шрифту и рамке. Проверки сцены проверяют геометрию на семи размерах экрана.

`node tests/browser.test.js` выполняет проверку через локальный Edge с включённым CDP на порту 9222: мобильная компоновка, полёт, отмена, возврат, список проектов, калькулятор, Telegram-черновик, загрузка локальных ресурсов и уменьшение движения. Корень определяется автоматически; снимки экрана сохраняются в `artifacts/previews/`. Профиль браузера следует размещать в `artifacts/browser/`. Папка `artifacts/` исключена из Git.

Относительные пути различаются по месту использования: главная ссылается на `css/`, `js/`, `pages/`; вложенные страницы — на `../css/`, `../js/`, `../assets/` и `../index.html`; стили — на `../assets/`.

## Приближение к исходному дизайн-плану

Актуальная концепция по последнему запросу: целая планета вместо нижней дуги и маяки вместо объёмных карточек. Доворот занимает до 0,65 секунды, приближение через облака — 0,9 секунды, затем открывается отдельная страница. Есть туманность, три слоя звёзд с параллаксом, атмосфера, движущиеся облака, астероиды и комета. Canvas увеличивается целым множителем: 4 на десктопе, 3 на мобильном.

Далее по плану: ручная доводка карты и спрайтов, реальные превью, проверка пересечений карточек и визуальная полировка на устройствах. Текущий процедурный арт — основа для этой доводки.

## Перед публикацией

Проверить статусы продуктов, актуальность ставок и исходящие ссылки. Обложки — схематичные иллюстрации, не скриншоты. Локальные кейсы содержат основные сведения; ссылки на старый сайт сохранены как дополнительные. При публикации на esscale.ru нужно сохранить старые маршруты `/wearninglords/` и `/scandere/` или настроить перенаправления. Проверить Telegram и жесты на реальных телефонах. Сайт пока не опубликован.

Контент и параметры оценки взяты с https://esscale.ru/. Правило округления и перемножение коэффициентов явно определены здесь и требуют сверки с исходным кодом перед заменой производственного калькулятора.
